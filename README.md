# Hamburg 2026 — interactive public city guide

A map-first website of 36 curated public locations collected for a November 2026 Hamburg visit.

**Public website:** https://karstenkelm.github.io/

## Files

- `index.html` — mobile-friendly page embedding the generated leafmap map, with an independently searchable/filterable list of places.
- `data/hamburg_places.geojson` — editable curated locations and descriptions.
- `build_map.py` — authoritative map generator using **Professor Qiusheng Wu's leafmap Folium backend**.\n- `leafmap-map.html` — generated interactive map embedded in the homepage (created by GitHub Actions).\n- `.github/workflows/build-leafmap.yml` — generates and commits the map when data or script changes.

## Build with leafmap

```sh
python -m pip install leafmap folium
python build_map.py
```

This writes `leafmap-map.html`, an interactive map with category layers embedded into the homepage. The list on the homepage has separate search/filter controls and opens Google Maps directions. The map itself is generated by leafmap, and GitHub Pages does not run Python for site visitors.

## Editing the website

Edit `data/hamburg_places.geojson` to add places, then commit to `main`. GitHub Pages should serve the update from its configured publishing branch. Coordinates are **approximate orientation markers**, not verified front-door coordinates. The Directions link searches for the venue name.

Only public attractions and businesses are included; private trip plans and accommodation are intentionally excluded.
