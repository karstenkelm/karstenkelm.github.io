# Hamburg Notes — a personal Hamburg field guide

A bilingual, editorial Hamburg website with 73 curated public locations across Food, Kneipen, Cocktails, Sights, Harbor, Shops, and Kodak Moments. The site combines an interactive city map with personal writing, Hamburg humor, photography viewpoints, and the Hanseatic Institute of Applied Stoicism.

**Public website:** https://karstenkelm.github.io/

## Files

- `index.html` — bilingual editorial homepage, Institute and shop sections, embedded English/German maps, and searchable/filterable places list.
- `data/hamburg_places.geojson` — editable curated locations and descriptions.
- `build_map.py` — authoritative map generator using **Professor Qiusheng Wu's leafmap Folium backend**.
- `leafmap-map.html` and `leafmap-map-de.html` — generated English and German maps embedded in the homepage.
- `.github/workflows/build-leafmap.yml` — regenerates and commits both maps when the dataset, generator, or workflow changes.
- `assets/` — website photography, graphics, and Institute merchandise imagery.

## Build with leafmap

```sh
python -m pip install leafmap folium
python build_map.py
```

This writes both `leafmap-map.html` and `leafmap-map-de.html`, interactive maps with category layers embedded into the homepage. The list on the homepage has separate search/filter controls and opens Google Maps directions. The map itself is generated by leafmap, and GitHub Pages does not run Python for site visitors.

## Editing the website

Edit `data/hamburg_places.geojson` to add places, then commit to `main`. The GitHub Actions map workflow regenerates both language maps; GitHub Pages publishes the resulting site. Coordinates are map markers and should be verified for individual destinations; Kodak Moments entries are intended as photography viewpoints. Directions links search for the venue name.

Only public attractions and businesses are included; private trip plans and accommodation are intentionally excluded.
